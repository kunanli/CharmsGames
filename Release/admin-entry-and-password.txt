# 管理员操作指引（入口与密码）

## 怎么进入管理员界面

1. 先进入任意一款游戏的二级标题画面（底部有 PRESS ANY BUTTON TO START 闪烁提示的画面）。
2. **同时按住 A 和 B 两个键，不要松手，坚持 3 秒**，会弹出密码界面。
   - 键盘上就是 **A 键 ＋ S 键**；手柄上就是 **A 钮 ＋ B 钮**。
   - 注意：如果没按满 3 秒就松手，会被当成普通按键、直接进入起名开局 —— 重新回到二级标题再试一次即可。

## 密码

用**方向键**依次输入（共 8 位）：

```
↑ ↑ ↓ ↓ ← → ← →
上上下下左右左右
```

- 键盘按方向键，或推手柄**左摇杆**都可以（摇杆每推一下算一位，推住不动不会连发，推完回正再推下一位）。

## 密码界面的按键

| **A** | 输满 8 位后按 A 确认 |
| **B** | 删掉最后输错的一位 | 没有密码时退出管理员登录密码界面

## 输完之后

- **密码正确** → 有确认音效，自动回到一级界面（可以选游戏或进 SETTING）。
- **密码错误** → 屏幕显示 WRONG PASSWORD，已输入的全部清空，从头再输一遍。
- **没输满 8 位就按 A** → 屏幕提示 8 DIRECTIONS NEEDED，继续输满再按 A。

## 回到一级界面后

- **↑ ↓** 选游戏（MAZE／FISHING／CATCH）或 SETTING，按 **A** 确认。
- 清除排行榜等管理功能都在 **SETTING** 里面（CLEAR LEADERBOARD → 选游戏 → 选清除范围）。
